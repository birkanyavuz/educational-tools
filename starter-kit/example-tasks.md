# Example tasks that use the catalog

1. **Grade 1 math week** — "Plan five short Grade 1 math activities for a week,
   one per day, covering counting, place value, making 10, missing addends, and
   addition/subtraction partners. Use search_classroom_tools for each skill and
   cite each activity's tool_id in the plan."
2. **Reading practice set** — "Build a Grade 1 reading practice set: one sight
   words activity, one CVC activity, one digraph activity, and one middle-sound
   activity. Return each tool's name, objective, and tool_id."
3. **Spanish warm-up** — "Find a Spanish syllables activity suitable for
   Grades 1-3 and describe a 10-minute warm-up using it. Cite the tool_id."
